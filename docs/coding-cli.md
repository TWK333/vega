# 编码与浏览器阶段工具

轻量主控调用 `code_agent({task})` 委托编码，调用 `browser_agent({task})` 委托网页操作，不直接调用 `chrome_*`。例如修复筛选器后需要网页验收：先由编码阶段返回改动与单测结果，再由轻量主控单独派发验收目标。CLI 回执同样先交回主控，退出码为零不代表网页验收通过。浏览器发现缺陷时返回复现条件和证据；只有原任务授权修复，主控才调用编码工具。两个阶段不能互相调用，也不能用旧 `switch_scene` 直接互转。

在设置的场景页，选择 **编码 → 执行方式**，然后保存场景。`model`（默认）保留原模型列表；`codex`、`antigravity` 分别要求执行端账号的 PATH 中已有且已登录的 `codex`、`agy`。旧版桌面 IDE 的启动命令不能代替支持 `--print` 的 agy。轻量和浏览器仍使用各自配置的模型。

## 查看与导出阶段记录

会话时间线上每次委托对应一张可展开的阶段卡。委托消息序号标识本次调用（不是模型名或任务文本）；两次委托同一个模型也不会合并。模型阶段沿用原会话保存工具参数、回执、图片引用及阶段说明。进入场景的回执不是验收通过；只有实际交回主控才显示「已交回」。任务暂停后仍沿用原委托，没收到返回记录就不标完成。

调试会话的 JSON 导出保留完整 `messages`，`agentPhases[].messageSeqs` 指向同一文件中的原消息，不重复存储日志和图片。旧记录仅按已有场景交接和工具回执关联，缺失部分不补造。Codex 的新记录额外保留已结束的命令（含退出码）与变更文件名，最多 80 项，不保存原始终端输出。Antigravity 的 `--print` 只提供阶段文本。导出可能包含项目路径、命令参数和页面数据，分享前应检查。

CLI 只收到编码交接文本，不转发完整会话或 Vega 密码本。绑定客户端就在该客户端运行；隔离云工作区在该用户的隔离环境运行。CLI 使用自己的账号和供应商，启用前确认允许发送该项目数据。不会自动安装、登录、跨设备或换模型。每次交接为一次非交互执行，最长 10 分钟；超时或中断先检查工作区，不能据此认定没有写入。审批、网页操作和对外提交留给 Vega，不给 CLI 传入跳过权限的参数。
