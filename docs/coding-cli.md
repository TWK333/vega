# 编码与浏览器阶段工具

主控调用 `code_agent({task})` 或 `browser_agent({task})`，不手动切换场景。目标明确时可以一次调用 `code_agent({task: '修复筛选器并运行单测', browserTask: '在既有测试页验证筛选器，勿提交表单'})`。模型编码阶段可直接交给浏览器；CLI 返回就绪标记后运行时直接派发已授权的验收目标。退出码为零本身不是验收通过。反过来，浏览器发现缺陷且原任务已授权修复时，也能直接调用 `code_agent`，再回浏览器复验；仅授权检查时报告问题，不擅自改代码。两个方向都不需要主控模型中转。旧 `switch_scene` 保持兼容。

在设置的场景页，选择 **编码 → 执行方式**，然后保存场景。`model`（默认）保留原模型列表；`codex`、`antigravity` 分别要求执行端账号的 PATH 中已有且已登录的 `codex`、`agy`。旧版桌面 IDE 的启动命令不能代替支持 `--print` 的 agy。轻量和浏览器仍使用各自配置的模型。

CLI 只收到编码交接文本及可选的网页验收目标，不转发完整会话或 Vega 密码本。绑定客户端就在该客户端运行；隔离云工作区在该用户的隔离环境运行。CLI 使用自己的账号和供应商，启用前确认允许发送该项目数据。不会自动安装、登录、跨设备或换模型。每次交接为一次非交互执行，最长 10 分钟；超时或中断先检查工作区，不能据此认定没有写入。审批、网页操作和对外提交留给 Vega，不给 CLI 传入跳过权限的参数。
